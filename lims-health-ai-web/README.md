# Limenss AI Healthcare Experience Platform (LHXP) — Website

A branding and product showcase website for the LHXP platform. Clean, calm, healthcare-grade design for building trust with doctors and clinics.

## Features

- **Hero** — Clear headline, CTAs, and connected ecosystem visual
- **Problem Section** — Real healthcare pain points
- **Solution Section** — Step-by-step flow (Patient ID → Doctor → Prescription → Hindi AI → Calmer clinics)
- **Platform Showcase** — Web, Mobile, Kiosk cards
- **Features by User** — Tabbed sections for Doctors, Clinics, Patients, Labs, Pharmacies, Family
- **Pandemic & Remote Care** — Healthcare that never shuts down
- **Differentiators** — Why LHXP is different
- **Trust & Credibility** — Built for real clinics, compliance-ready
- **CTA Section** — Demo/Pilot request form (sends enquiries to info.limenssgroup@gmail.com)
- **Footer** — Links and AI disclaimer

## Tech Stack

- React 18 + Vite
- Tailwind CSS
- Mobile-first responsive design

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Contact Form & Email

The enquiry form uses [FormSubmit](https://formsubmit.co) to send submissions to **info.limenssgroup@gmail.com**. On the **first submission**, FormSubmit sends a one-time confirmation email to that address — click the link to activate. After that, all enquiries will be delivered with the full details (clinic name, city, contact number, email, type).

## Design Principles

- Clean, calm, healthcare-grade
- White / light backgrounds, soft blue & green accents
- Rounded cards, smooth transitions
- Minimal text, strong visuals
- Non-technical, trustworthy tone
